========================================
TROUBLESHOOTING
========================================

Issue: "Invalid credentials"
→ Verify ADMIN_EMAIL and ADMIN_PASSWORD are set correctly
→ Check for trailing spaces in environment variables
→ Ensure values match exactly (case-sensitive)

Issue: "Session expired"
→ Session lasts 8 hours
→ Log in again to start new session
→ Clear browser cookies if needed

Issue: KPIs showing zero
→ Database may be empty (new deployment)
→ Create test orders/invoices to populate data
→ Verify database connection is active
